# 植物大战僵尸 · 网页基础版

目标：先完成接近原版玩法的可玩网页游戏，再在最终阶段替换经用户审核的奶蛙植物和僵尸素材。当前版本使用网上获取的经典游戏素材，来源见 dist/ASSET_SOURCES.md。

## 已实现
- 10 个自编白天渐进关卡：单行、三行、五行开放与逐关植物解锁。
- 九种植物：豌豆射手、向日葵、樱桃炸弹、坚果、土豆地雷、寒冰射手、双发射手、火爆辣椒、高坚果。
- 三种僵尸：普通、路障、铁桶；包括行走、啃食、护具脱落、死亡和爆炸死亡表现。
- 50 初始阳光、天空阳光、向日葵生产、卡片冷却、射击、减速、爆炸、地雷准备、整行火焰、坚果损伤、铲子和每行一次割草机。
- 无尽草坪、暂停、倍速、辅助网格、可选自动收光、可选音效、浏览器本地进度。
- 下载即玩的单文件离线版和完整项目 ZIP。

这是基础版，不是完整原版移植。当前未实现夜晚、泳池、屋顶、原版全部植物/僵尸、小游戏和全部关卡；当前十关为渐进教学与战斗关卡，不声称是原版逐关复刻。奶蛙素材尚未接入。

## 运行
直接打开 dist/index.html 时，部分浏览器会限制 fetch；无需安装工具，使用部署地址或下载 dist/game-offline.html（内嵌全部必需素材）。

## 结构
- dist/js/engine.js：独立于渲染的可复现战斗逻辑，单位为秒和网格。
- dist/js/renderer.js：PNG 动画图集渲染；画布 1100×600，种植区 x=250,y=85，每格 80×96，五行九列。
- dist/js/app.js：鼠标/触屏操作、关卡进度、界面、音效。
- dist/assets/manifest.json：素材尺寸、帧数、帧时长；后续奶蛙素材替换入口。
- tests/engine.test.js：关键玩法测试。
- tests/ui-smoke.js：界面启动、操作及真实 Canvas 素材绘制检查。
- tests/balance.js：正常经济的启发式自动玩家，三随机种子/关；用于诊断，不代表人工验收。
- tests/render.js：实际素材战场渲染检查。
- scripts/package.py：生成离线 HTML 与项目 ZIP。
- scripts/prepare_assets.py：将下载 GIF 转换为图集；使用 --input 指定原素材目录，不是运行依赖。

## 验证记录
13 项模拟测试、界面操作检查与 31 份动画图集校验通过。战场、选格、植物损伤和爆炸已实际渲染查看。自动玩家以正常初始阳光与收入，在三个种子下均完成前六关，后四关出现胜负两种结果。尚未在真实浏览器/Safari/iPad 上运行，未完成人工难度验收与长时间无尽压力验证。

## GitHub 开发与自动部署

- `main` 是发布分支，提交后先运行语法、战斗模拟及素材检查，全部通过后自动发布 `dist/` 到 GitHub Pages。
- Pull Request 只检查、不发布；合并到 `main` 后发布。
- GitHub 仓库的 Settings → Pages 发布来源设为 GitHub Actions；首次接入时由助手配置。
- 所有游戏资源使用相对路径，支持 `https://账号.github.io/仓库名/` 的项目站点。
- 离线 HTML 和完整项目下载包在部署时生成，不把重复生成的大文件提交到 Git。
- 修改代码或素材后使用 `node tests/engine.test.js` 和 `python3 scripts/validate_site.py` 检查；生成下载包使用 `python3 scripts/package.py`。
- 仅重新导入原始 GIF 素材时需要 Pillow：`python3 scripts/prepare_assets.py --input 原素材目录`；正常开发、运行和部署均不需要它。
- 可选 Canvas 渲染检查依赖 `@napi-rs/canvas`，不是运行或 Pages 部署依赖。
- 未来奶蛙素材替换应集中调整 `dist/assets/manifest.json` 与素材对应项，不改动网格坐标。
